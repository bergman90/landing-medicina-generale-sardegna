# Landing page QR WhatsApp

Landing page statica pronta per GitHub Pages.

## Personalizzazione

1. Apri `index.html`.
2. Sostituisci questo valore con il link reale del canale WhatsApp:

```html
https://whatsapp.com/channel/INSERISCI-QUI-IL-TUO-CANALE
```

I materiali scaricabili definitivi andranno caricati in:

- `materiali/` per la lettera in PDF
- `assets/` per i JPEG della mobilitazione

## Pubblicazione su GitHub Pages

1. Crea un nuovo repository su GitHub.
2. Carica questi file nel branch `main`.
3. Vai in `Settings` > `Pages`.
4. In `Build and deployment`, scegli `GitHub Actions`.
5. Il workflow pubblichera il sito automaticamente.

Quando GitHub Pages avra finito, usa l'URL pubblico generato da GitHub per creare il QR code del manifesto.
